# ENES-LifeWatch User Story

This folder contains the notebooks and supporting material developed for the joint ENES-LifeWatch user story within the [EOSC Beyond project](https://www.eosc-beyond.eu). 

The workflow explores the integration of biodiversity observations provided by LifeWatch ERIC with climate data and services provided by ENES (European Network for Earth System Modelling).

More specifically, the notebooks guide the user through the main steps of the workflow: 
- discovering the relevant EOSC resources
- accessing and querying LifeWatch biodiversity observations
- discovering climate data
- combining the two sources by associating biodiversity observations with corresponding climatic conditions

The resulting enriched dataset can then be visualised and further analysed within the [ENESLab environment](https://ds.eneslab.pilot.eosc-beyond.eu/jupyter/hub/login). 
The workflow also demonstrates how the provenance of the data, services and processing steps can be captured and explored using the ENES Provenance services.

The notebooks are organised sequentially and are intended to be followed in numerical order (`0_` to `5_`). 
Supporting data, generated outputs and images used by the notebooks are included in the corresponding folders.
